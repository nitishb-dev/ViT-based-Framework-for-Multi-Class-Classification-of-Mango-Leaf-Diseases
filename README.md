# ViT-based-Framework-for-Multi-Class-Classification-of-Mango-Leaf-Diseases
A Vision Transformer-based framework for classifying mango leaf diseases into 8 classes using Tiny Swin V2, Attention-Guided MixUp, PolyLoss, SAM optimizer, and LoRA-tuned ViT head. Achieves high accuracy with lightweight, efficient deployment.
